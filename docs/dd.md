# 画面設計ドキュメント（DD）

## 1. トップページ・タグ別記事一覧ページ（統合）

### 役割
- サイトのホーム。最新記事を一覧表示する。
- タグが指定された場合は、そのタグが付与された記事のみを一覧表示する。

### 主な内容・要素
- サイトタイトル・ロゴ（共通コンポーネント）
- タグ名（タグ指定時のみ表示）
- 記事一覧（新着順またはタグ絞り込み、ページネーションあり）
  - 記事タイトル
  - アイキャッチ画像
  - 公開日
  - タグ（複数）
  - 記事概要（抜粋）
  - 記事詳細ページへのリンク
- 「記事がありません」表示（記事が存在しない場合）
- ページネーションUI（前へ・次へ、ページ番号など）
- 共通サイドバー（共通コンポーネント）
  - 人気記事ランキング（CSRでAPI取得、APIエラー時のハンドリングも考慮）
  - タグ一覧（クリックでタグ別記事一覧へ遷移、全ページ共通で常時表示）

#### エンドポイント設計
- `/` : 記事一覧（新着順）
- `/tag/[tagId]` : タグ別記事一覧（tagIdで絞り込み）
- `*` : 404ページ（存在しない記事やタグの場合）

---

## 2. 記事詳細ページ

### 役割
- 記事の本文を表示する。

### 主な内容・要素
- サイトタイトル・ロゴ（共通コンポーネント）
- 記事タイトル
- アイキャッチ画像
- 公開日
- タグ（複数、クリックでタグ別記事一覧へ遷移）
- 記事本文（リッチテキスト）
- 共通サイドバー（共通コンポーネント）
  - 人気記事ランキング（APIエラー時のハンドリングも考慮）
  - タグ一覧（全ページ共通で常時表示）
- 404ページ（存在しない記事の場合）

#### エンドポイント設計
- `/article/[articleId]` : 記事詳細ページ
- `*` : 404ページ

---

## 3. 共通コンポーネント

- サイトタイトル・ロゴ
- サイドバー
  - 人気記事ランキング（CSRでAPI取得、APIエラー時のハンドリングも考慮）
  - タグ一覧（全ページ共通で常時表示）
- レスポンシブデザイン（PC/タブレット/スマホ対応）
- サイト全体でSEO対応（title, meta description, OGPタグ）
- サイト全体のフッター（著作権表記や運営情報等）

---

## 4. その他・運用上の注意

- 404ページ（存在しない記事やタグの場合）は必ず設計・実装すること。
- サイト全体のアクセシビリティ（alt属性、コントラスト、キーボード操作など）に配慮すること。
- サイトパフォーマンス（画像の最適化、遅延読み込み等）も考慮すること。
- サイト全体の多言語対応（必要に応じて）

---

※ トップページとタグ別記事一覧ページは1つのページ（コンポーネント）で実装し、URLパラメータで分岐します。
